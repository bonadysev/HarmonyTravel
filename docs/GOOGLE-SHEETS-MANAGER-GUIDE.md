# Инструкция для менеджера: туры в Google Sheets

## 1. Как добавить новый тур

1. Откройте лист `tours`.
2. Добавьте новую строку, не меняя названия колонок.
3. Заполните обязательные поля.
4. Для нового тура сначала установите:

```text
publishStatus: draft
active: false
```

5. Проверьте текст, стоимость, даты и фотографию.
6. После проверки измените статус на `published` и установите `active: true`.

## 2. Значения `publishStatus`

### `draft` — черновик

Тур находится в работе. Он не отображается на сайте.

Используйте этот статус, пока не заполнены все данные.

### `published` — опубликован

Тур готов к показу на сайте. Для отображения также необходимо:

```text
active: true
```

### `archived` — архив

Тур больше не предлагается. Он не отображается на сайте, но остаётся в таблице для истории.

## 3. Значения `active`

| Значение | Что происходит |
| --- | --- |
| `true` | Тур может отображаться, если `publishStatus = published` |
| `false` | Тур временно скрыт с сайта |

`active: false` удобно использовать, если набор временно закрыт или поездку нужно быстро убрать с сайта.

## 4. Обязательные поля листа `tours`

Нельзя удалять, переименовывать или переставлять названия колонок в первой строке.

Обязательные поля:

```text
id
active
publishStatus
category
title
location
date
age
duration
price
description
features
```

Дополнительные поля:

```text
included
note
colorClass
imageFile
imageAlt
```

## 5. Как заполнять поля

- `id` — уникальный идентификатор на английском языке через дефис. Например: `sula-history-park`.
- `active` — только `true` или `false`.
- `publishStatus` — только `draft`, `published` или `archived`.
- `category` — одно из значений: `Языковые`, `Активные`, `Морские`, `Экскурсионные`.
- `title` — название тура для карточки.
- `location` — город или место поездки.
- `date` — дата выезда или текст `ДАТА ВЫЕЗДОВ ОБНОВЛЯЕТСЯ`.
- `age` — возраст или целевая группа детей.
- `duration` — например, `1 день`.
- `price` — например, `125 руб.` или `126 руб. до 14 лет / 130 руб. старше 14 лет`.
- `description` — короткое описание тура.
- `features` — пункты через вертикальную черту `|`.
- `included` — что входит в стоимость, также через `|`.
- `note` — питание, рассрочка или дополнительные условия.
- `imageFile` — только имя файла, например `sula.jpeg`.
- `imageAlt` — краткое описание фотографии для доступности.

Пример поля `features`:

```text
Интерактивная экскурсия|Катание на Драккаре|Мастер-класс у ремесленников
```

## 6. Фотография тура

Фотография должна находиться в проекте в папке:

```text
public/tours/
```

В Google Sheets указывается только имя файла:

```text
dukorsky-maentak.jpeg
```

Имя в таблице должно полностью совпадать с именем файла, включая расширение и регистр букв.

Если файл называется `Sula.jpeg`, нельзя указывать `sula.jpeg`.

## 7. Связь с листом `departures`

Чтобы добавить тур в блок «Ближайшие выезды»:

1. Сначала добавьте тур в `tours`.
2. Убедитесь, что его `id` заполнен правильно.
3. На листе `departures` в поле `linkedTourId` укажите тот же `id`.

Пример:

```text
tours.id: sula-history-park
departures.linkedTourId: sula-history-park
```

Выезд появится на сайте только если связанный тур имеет:

```text
publishStatus: published
active: true
```

## 8. Перед публикацией проверьте

- нет ли повторяющегося `id`;
- заполнены ли обязательные поля;
- выбран ли правильный `category`;
- указан ли статус `published` только у готового тура;
- совпадает ли имя фотографии с файлом в `public/tours`;
- совпадает ли `linkedTourId` с `id` тура;
- указана ли корректная стоимость;
- нет ли лишних запятых и переносов внутри ячеек.

После изменения статуса сайт обновится во время следующей синхронизации GitHub Actions, которая запускается раз в час. Также синхронизацию можно запустить вручную в GitHub Actions.

Если в опубликованном туре есть ошибка, синхронизация остановится, а предыдущая рабочая версия сайта сохранится.
